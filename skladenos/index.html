skladenOS

Система для Skladen и других складных устройств: Mobian (Debian) с оконным менеджером SXMO, ядро 7.2 с нашими патчами зарядки и USB-PD, мастер первой загрузки и набор пакетов.

Исходники и репозиторий пакетов открыты. Готового образа для скачивания пока нет: его собирают из исходников одной командой.

Что это

skladenOS — система для Xiaomi Poco F1 (SDM845), в первую очередь в составе палмтопа Skladen, где экран и клавиатура соединены шарниром. Основа — Mobian (Debian forky) с лёгким интерфейсом SXMO (sway): жесты, кнопки громкости, внешняя клавиатура. Окна и панели не заходят под вырез и скруглённые углы экрана, даже в полноэкранном режиме.

Что работает

Вырез и углы
Панель и окна отступают от выреза и перестраиваются при повороте экрана.
Кнопки и жесты
Питание, громкость, жесты по краям экрана; с внешней клавиатуры работает Super+Esc.
Первая загрузка
Мастер на 12 языках (английский по умолчанию): Bluetooth-клавиатура, Wi-Fi, имя пользователя и обязательная смена пароля.
USB и зарядка
Роль хоста или устройства выбирается сама; хаб, флешка и клавиатура работают; зарядка по USB-PD.
Питание
Режимы «Баланс», «Экономия», «Ночь» и «Производительность» из меню, режим «экран не гаснет».
Раскладки
Английская и русская по CapsLock, экранная клавиатура с кириллицей.
Звук, датчики, сеть
Оба динамика, микрофон, датчики через SLPI на ядре 7.x, Wi-Fi и Bluetooth.
Защита тача
Сторож перезапускает драйвер тачскрина, если касание «зависло».
fastfetch
Показывает логотип skladenOS и название системы.

Проверено на Pocophone F1 (панель EBBG) с ядром 7.2: образ, собранный из исходников, прошит и работает. Вариант панели Tianma собирается, но на железе не проверен. SIM не проверялась.

Первая загрузка

Сразу после прошивки вход: пользователь skladen, пароль 1234. На экране запускается мастер: выбор языка, поиск Bluetooth-клавиатуры, Wi-Fi, затем имя пользователя и новый пароль. Пока пароль по умолчанию не сменён, вход по SSH разрешён только из локальных сетей. Имя пользователя применяется после перезагрузки.

Как собрать и прошить

Нужны Mac или Linux, Docker, fastboot и разблокированный загрузчик. Образ собирается в Docker из официального rootfs Mobian, наших пакетов и ядра (около пяти минут). Прошивка стирает весь телефон.

git clone https://github.com/mitya-labs/skladenos.git && cd skladenos
packages/build.sh skladenos-config        # и так для каждого пакета skladenos-*
build/image/build.sh build                # образ в out/image/<метка>/ , около 5 минут
scripts/snapshot-flash out/image/<метка>   # стирает весь телефон!

Подробности, предварительные условия и «подводные камни»: README в репозитории.

Пакеты из репозитория

Пакеты лежат в подписанном apt-репозитории, релиз garmon (arm64). В образе источник уже включён; на другой системе на Poco F1:

curl -fsS https://mitya-labs.github.io/apt/skladenos-archive-keyring.gpg | sudo tee /usr/share/keyrings/skladenos-archive-keyring.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/skladenos.sources >/dev/null <<'EOF'
Types: deb
URIs: https://mitya-labs.github.io/apt/
Suites: garmon
Components: main non-free
Signed-By: /usr/share/keyrings/skladenos-archive-keyring.gpg
EOF
sudo apt update

Отпечаток ключа подписи: B27E 8856 988A 9019 BB9A 23F2 BBBD 1474 A352 F720.

Эмуляторы

HP Jornada 720 (Windows CE, QEMU) и Psion 5mx (EPOC, WindEmu) ставятся пакетами skladenos-emu-jornada720 и skladenos-emu-psion и запускаются из меню Scripts в SXMO. ROM в пакеты не входят, нужен свой: ~/roms/jornada720.bin и ~/roms/5mx_eng.bin. Сборка эмуляторов воспроизводится в Docker из наших форков (qemu-jornada720, WindEmu).
