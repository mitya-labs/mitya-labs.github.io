Skladen

Skladen is a palmtop that turns a Xiaomi Pocophone F1 into a pocketable laptop-shaped terminal. The name is skladen (складень), a hinged Russian travel icon: two panels that fold shut over what they carry.

The lid holds the phone under a clip-on bezel, the base carries a Jomaa KEYBOARD098RU salvaged from a folio case. Everything is printed, and the hinge sits on two M3 bolts. The design is written as code (build123d): dimensions and checks are computed when the model is built.

skladenOS

skladenOS is the system for Skladen and other folding devices where the screen and the keyboard are joined by a hinge. It is Mobian (Debian) with the SXMO window manager: a light interface driven by gestures, volume keys and an external keyboard. It respects the display notch and rounded corners: windows and bars never go under the cutout, even in fullscreen.

The source and the package repository are open. There is no ready-made image to download yet: the image is built from source with one command (Docker).

Basis and rights

Skladen: the design is open under CERN-OHL-S-2.0; the Python model counts as the source.

skladenOS is based on Mobian and Debian, but it is not an official release of either and is not affiliated with those projects. We do not distribute Qualcomm or Xiaomi firmware: the system extracts it on the phone itself.
