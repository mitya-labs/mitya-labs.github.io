Mitya Labs builds Skladen, a 3D-printed palmtop that turns a Xiaomi Pocophone F1 into a pocketable laptop-shaped terminal, and skladenOS, the system for it.

Skladen 2.1 is printed and assembled. skladenOS is in development: there are no images yet.

Skladen

Skladen is a palmtop that turns a Xiaomi Pocophone F1 into a pocketable laptop-shaped terminal. The name is skladen (складень), a hinged Russian travel icon: two panels that fold shut over what they carry.

The lid holds the phone under a clip-on bezel, the base carries a Jomaa KEYBOARD098RU salvaged from a folio case. Everything is printed, and the hinge sits on two M3 bolts. The design is written as code (build123d): dimensions and checks are computed when the model is built.

skladenOS

skladenOS is the system for Skladen and other folding devices where the screen and the keyboard are joined by a hinge. It is Mobian (Debian) with the SXMO window manager: a light interface driven by gestures, volume keys and an external keyboard. It respects the display notch and rounded corners: windows and bars never go under the cutout, even in fullscreen.

There are no images to download yet: building from source and testing on the device are still under way.

What works today

Notch and corners
The bar and windows keep clear of the cutout and adjust when the screen rotates.
Buttons and gestures
Power, volume, edge gestures; Super+Esc works from an external keyboard.
USB
Host or device role is picked automatically: a hub, a flash drive and a keyboard work; USB networking comes up with a computer.
Power
“Balanced”, “Eco”, “Night” and “Performance” profiles from the menu, plus a “keep screen awake” mode.
Layouts
English and Russian switched with CapsLock, on-screen keyboard with Cyrillic.
Audio and sensors
Both speakers, sensors through the SLPI on kernel 7.x.

Verified on a working build with a Pocophone F1 and kernel 7.2. The new from-source build is still being tested on the device.

How it is built

  1. KernelThe Mobian SDM845 kernel from source plus our patches: Type-C and PD charging.
  2. PackagesDevice and SXMO settings are shipped as deb packages.
  3. ImageMobian recipes (debos) assemble an image from the kernel and the packages.
  4. FlashingThe image is flashed to the phone with fastboot.

Kernel and recipe versions are pinned, and the build is planned to run in CI on GitHub, so the image can be reproduced from source.

Basis and rights

Skladen: the design is open under CERN-OHL-S-2.0; the Python model counts as the source.

skladenOS is based on Mobian and Debian, but it is not an official release of either and is not affiliated with those projects. The SXMO window manager is distributed under the AGPL-3.0. We do not distribute Qualcomm or Xiaomi firmware: the system extracts it on the phone itself. The license of the skladenOS code will be announced when the repository opens.
