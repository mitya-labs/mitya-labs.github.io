skladenOS

The system for Skladen and other folding devices: Mobian (Debian) with the SXMO window manager, a 7.2 kernel with our charging and USB-PD patches, a first-boot wizard and a set of packages.

The source and the package repository are open. A ready-made image for the Poco F1 (EBBG panel) is in the v0.1.0 release on GitHub; you can also build it from source with one command.

Releases: image v0.1.0 →garmon repository (apt) →

Release: the Poco F1 (EBBG) image, kernel and packages. garmon: the signed apt repository the phone gets its updates from.

What it is

skladenOS is the system for the Xiaomi Poco F1 (SDM845), first of all as part of the Skladen palmtop, where the screen and the keyboard are joined by a hinge. It is built on Mobian (Debian forky) with the light SXMO (sway) interface: gestures, volume keys, an external keyboard. Windows and bars keep clear of the notch and the rounded corners, even in fullscreen.

What works

Notch and corners
The bar and windows keep clear of the cutout and adjust when the screen rotates.
Buttons and gestures
Power, volume, edge gestures; Super+Esc works from an external keyboard.
First boot
A wizard in 12 languages (English by default): Bluetooth keyboard, Wi-Fi, user name and a required password change.
USB and charging
Host or device role is picked automatically; a hub, a flash drive and a keyboard work; USB-PD charging.
Power
“Balanced”, “Eco”, “Night” and “Performance” profiles from the menu, plus a “keep screen awake” mode.
Layouts
English and Russian switched with CapsLock, on-screen keyboard with Cyrillic.
Audio, sensors, network
Both speakers, microphone, sensors through the SLPI on kernel 7.x, Wi-Fi and Bluetooth.
Touch watchdog
A service resets the touchscreen driver when a touch gets stuck.
fastfetch
Shows the skladenOS logo and the system name.

Verified on a Pocophone F1 (EBBG panel) with kernel 7.2: an image built from source is flashed and runs. The Tianma panel variant builds but is not verified on hardware. The SIM has not been tested.

First boot

Right after flashing, log in as skladen with the password 1234. A wizard starts on screen: language, a Bluetooth keyboard search, Wi-Fi, then a user name and a new password. Until the default password is changed, SSH password login is allowed only from local networks. The new user name takes effect after a reboot.

How to build and flash

You need a Mac or Linux, Docker, fastboot and an unlocked bootloader. The image is assembled in Docker from the official Mobian rootfs, our packages and the kernel (about five minutes). Flashing erases the whole phone.

git clone https://github.com/mitya-labs/skladenos.git && cd skladenos
packages/build.sh skladenos-config        # repeat for each skladenos-* package
build/image/build.sh build                # image in out/image/<label>/, about 5 minutes
scripts/snapshot-flash out/image/<label>   # erases the whole phone!

Details, prerequisites and pitfalls: the README in the repository.

Packages from the repository

The packages live in a signed apt repository, release garmon (arm64). The image already has the source enabled; on another system on a Poco F1:

curl -fsS https://mitya-labs.github.io/apt/skladenos-archive-keyring.gpg | sudo tee /usr/share/keyrings/skladenos-archive-keyring.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/skladenos.sources >/dev/null <<'EOF'
Types: deb
URIs: https://mitya-labs.github.io/apt/
Suites: garmon
Components: main non-free
Signed-By: /usr/share/keyrings/skladenos-archive-keyring.gpg
EOF
sudo apt update

Signing key fingerprint: B27E 8856 988A 9019 BB9A 23F2 BBBD 1474 A352 F720.

Emulators

HP Jornada 720 (Windows CE, QEMU) and Psion 5mx (EPOC, WindEmu) install as the packages skladenos-emu-jornada720 and skladenos-emu-psion and start from the Scripts menu in SXMO. ROMs are not included; bring your own: ~/roms/jornada720.bin and ~/roms/5mx_eng.bin. The emulators are built reproducibly in Docker from our forks (qemu-jornada720, WindEmu).
